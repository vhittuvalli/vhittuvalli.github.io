DriveSim

JavaScript · three.js · PyTorch · ONNX Runtime Web

A self-driving car simulator that runs in the browser: a procedural city and six-lane highway with traffic that changes lanes, weather, and 11 pass/fail scenarios. The car is driven by a network I trained in PyTorch on 344K frames from 895 automated runs, running live in the page. An expert driver labels the data and rides along as a safety driver.

VPN

Go · post-quantum cryptography · macOS

A VPN written from scratch in Go, built like WireGuard with ML-KEM and ML-DSA added so recorded traffic stays private against future quantum computers. It ships as a Mac menu bar app with a kill switch and trusted Wi-Fi, plus a server you set up with one command and share with invite keys.
